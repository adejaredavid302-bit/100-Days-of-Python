# Day 22 – Pong Game

## Overview

Day 22 focused on building a classic **Pong Game** using Python's Turtle graphics module.

This project continued the Object-Oriented Programming concepts introduced in the previous days. Instead of putting the entire game into one file, the project was organized into different classes and modules responsible for the paddles, ball, scoreboard, and game behavior.

The project helped me understand how multiple Python classes can work together to create a complete interactive game.

## Topics Covered

* Object-Oriented Programming

* Class attributes and methods
* Inheritance
* The `Turtle` class
* Creating custom classes from existing classes
* Object movement
* Keyboard controls
* Collision detection

* The `xcor()` and `ycor()` methods
* The `distance()` method
* The `goto()` method

* Random movement
* Score tracking
* Multiple Python modules working together
* Using objects from different classes
* Game loops and game logic

## What I Learned

One of the main things I learned was how to use **Object-Oriented Programming to organize a larger Python project**.

Instead of putting everything into one file, I learned that different parts of a game can have their own classes. Each class can have its own responsibility while the main program connects everything together.

I also became more comfortable with inheritance and learned how a class can inherit functionality from another class.

I learned how the Turtle module can be used to create game objects and control their movement on the screen.

Collision detection was another important concept. I learned how to use coordinates and methods such as `xcor()`, `ycor()`, and `distance()` to determine where objects are and when they interact with each other.

I also learned how keyboard events can control objects and how a game continuously updates while the program is running.

## Challenges

One of the biggest challenges was understanding how the different objects communicate with each other.

At first, it was difficult to understand how the paddle, ball, scoreboard, and main game could all be separate objects but still work together.

Understanding coordinates and collision detection also required careful attention because small changes in the ball's position could affect the entire game.

Another challenge was understanding how inheritance works when creating classes based on the Turtle class.

## Reflection

Day 22 helped me understand why Object-Oriented Programming becomes more useful as programs become larger.

Instead of thinking about the entire game as one large block of code, I started thinking about each part as an object with its own responsibility.

The project also helped me become more comfortable reading code that uses multiple classes and files.

I am beginning to understand that good programming is not only about making the code work, but also about organizing the code so that it is easier to understand, reuse, and modify.

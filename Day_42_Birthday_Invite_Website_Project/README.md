# Day 42 – Birthday Invite Website

## Overview

This project is a simple birthday invitation website created using HTML.

The webpage displays a birthday invitation with a heading, date, image, list of items to bring, and a Google Maps link showing the location.

## Topics Covered

* HTML headings
* HTML paragraphs
* HTML images
* Image attributes
* HTML lists
* Unordered lists
* HTML anchor elements
* The `href` attribute
* Nested HTML elements

## What I Learned

In this project, I learned how to combine different HTML elements to create a complete webpage.

I practiced:

* Using `<h1>`, `<h2>`, and `<h3>` for headings
* Adding images using the `<img>` element
* Using the `src` attribute to specify an image source
* Using the `alt` attribute to describe an image
* Creating lists using `<ul>` and `<li>`
* Creating clickable links using the `<a>` element
* Using the `href` attribute to specify where a link should go

## Project Features

The birthday invitation includes:

* A birthday heading
* The birthday date
* A birthday cake image
* A list of items to bring
* A Google Maps link showing the location

## Challenges

One challenge was understanding how different HTML elements work together on the same webpage.

I also practiced using attributes such as `src`, `alt`, and `href`.

## Reflection

This project helped me understand how individual HTML elements can be combined to create a simple and useful webpage.

I am becoming more comfortable with HTML structure, elements, attributes, images, lists, and links.

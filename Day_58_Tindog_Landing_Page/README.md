# Day 58 — TinDog Landing Page

## Overview
For Day 58 of Angela Yu’s 100 Days of Code: The Complete Python Pro Bootcamp, I built a responsive landing page for **TinDog**, a fictional dating app for dogs. This project focused on using Bootstrap to create a clean, modern website that adapts to different screen sizes.

## Features
- Responsive hero section with a headline and download buttons.
- Features section highlighting the benefits of TinDog.
- Testimonial section with a customer quote and company logos.
- Pricing section featuring three subscription plans.
- Footer with navigation links.
- Responsive layouts using Bootstrap's grid system.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Grid System
- Bootstrap Utility Classes
- SVG icons

## What I Learned
- How Bootstrap's container, row, and column system works.
- How to use responsive breakpoints such as `sm`, `md`, `lg`, `xl`, and `xxl`.
- How to arrange content using classes such as `col-lg-6` and `row-cols-md-3`.
- How to use Bootstrap utility classes for spacing, alignment, typography, and buttons.
- How to build responsive feature sections and pricing cards.
- How to combine Bootstrap components with custom CSS.

## Challenges Faced
Understanding how Bootstrap's grid system divides a row into 12 units and how responsive classes change the layout at different screen sizes.

## What I Learned From This Project
This project helped me understand how Bootstrap makes responsive web design easier by providing reusable layout classes and styling utilities. I also learned how to combine Bootstrap with custom CSS to create a polished landing page.

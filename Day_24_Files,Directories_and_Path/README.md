## What I Learned

During Day 24, I learned how Python finds and accesses files.

I learned the difference between an **absolute path** and a **relative path**.

An absolute path gives the complete location of a file, while a relative path tells Python how to reach the file from the current location.

I also learned the basic relative-path symbols:

* `.` means the current directory.
* `..` means go up one directory.
* `folder/` means go inside a folder.
* `../` means go up one directory.
* `../../` means go up two directories.

I practiced using paths with `open()` to access files and read their contents.

# Day 55 – Number Guessing Game

## Overview
Built a simple number guessing game using Flask. The application generates a random number between 0 and 9 and allows users to guess by entering a number in the URL.

## Topics Covered
- Flask application setup
- Flask route decorators
- Dynamic URL parameters using `<int:number>`
- Random number generation with `random.randint()`
- Conditional statements (`if`, `elif`)
- Comparing integers
- Returning HTML from Flask routes
- Displaying GIF images in HTML responses

## What I Learned
- How to use Flask routes to handle different URLs.
- How Flask converts a URL parameter into an integer using `<int:number>`.
- How to compare a user's guess with a randomly generated number.
- How to return HTML headings and images from a Flask function.
- How to use conditional statements to display different responses.

## Challenges
- Understanding how Flask passes URL values into a function.
- Correctly formatting HTML image tags inside Python strings.
- Writing comparison messages for guesses that are too high or too low.

## Reflection
This challenge helped me understand how Flask routes, dynamic URL parameters, Python conditionals, and HTML responses work together to create a simple interactive web application.

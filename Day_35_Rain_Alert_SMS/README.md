# Day 35 – Rain Alert SMS

## Overview

On Day 35 of the 100 Days of Code challenge, I built a **Rain Alert SMS** project using Python.

The program uses the OpenWeatherMap API to retrieve weather forecast data for a specific location. It checks the forecast for rain using the weather condition ID. If rain is expected, the program uses Twilio to send an SMS notification.

## Topics Covered

* API requests with `requests`
* API parameters
* JSON data
* Nested dictionaries and lists
* `for` loops
* `if` statements
* Boolean variables
* OpenWeatherMap API
* Twilio API
* Sending SMS messages
* API authentication

## What I Learned

* How to make requests to the OpenWeatherMap API.
* How to send parameters such as latitude, longitude, API key, and forecast count.
* How to access nested information from JSON responses.
* How to loop through weather forecast data.
* How to use weather condition IDs to determine whether rain is expected.
* How Boolean variables can be used to keep track of a condition.
* How to connect Python with Twilio to send SMS messages.
* How APIs can be used together to create automated applications.

## Challenges

One of the main challenges was understanding the structure of the weather data returned by the API.

I also had to work through nested lists and dictionaries to access the weather condition ID.

Another challenge was working with Twilio and understanding how SMS messages are sent through its API.

## Reflection

Day 35 gave me more practice working with real-world APIs and JSON data.

I learned how Python can take information from an external service, make a decision based on that information, and then automatically perform an action.

This project helped me understand how APIs can be combined with automation to create useful applications.

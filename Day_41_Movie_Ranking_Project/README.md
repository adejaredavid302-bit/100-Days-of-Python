## Topics Covered

* HTML
* Heading elements

* Void elements

## What I Learned

Today, I learned that HTML is used to structure the content of a webpage.

I also learned:

* `<h1>` to `<h6>` are used for headings.
* `<p>` is used for paragraphs.
* `<hr>` creates a horizontal line to separate content.
* `<br>` creates a line break.
* Some HTML elements, called void elements, do not require closing tags.

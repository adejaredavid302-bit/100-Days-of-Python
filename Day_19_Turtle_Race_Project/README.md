# Day 19 – Turtle Race Project

## Overview

Day 19 focused on using multiple Turtle objects to create a simple racing game. I learned how to manage several objects at once, collect user input, generate random movement, and determine a winner based on each turtle's position.

The project simulates a turtle race where the user places a bet on which turtle will win before the race begins.

## What I Learned

- How to create multiple objects from the same class.
- How to store objects inside a list.
- How to loop through a list of objects.
- How to move each turtle independently using random values.
- How to use `xcor()` to check an object's x-coordinate.
- How to use `pencolor()` to identify the winning turtle.
- How to collect user input using `screen.textinput()`.
- How to stop a game loop when a winning condition is met.
- How objects can have both attributes and methods.

---

## Project

### Turtle Race

This project creates five turtles with different colors. The user places a bet on which turtle they think will win the race. Each turtle moves forward by a random distance until one crosses the finish line. The program then announces whether the user's prediction was correct.

---

## Challenges

- Understanding how to work with multiple Turtle objects at once.
- Learning how to store objects inside a list.
- Figuring out how to detect when a turtle reaches the finish line.
- Comparing the user's bet with the winning turtle's color.
- Understanding the difference between object methods such as `xcor()` and `pencolor()`.

# Day 23 – Turtle Crossing

## Overview

Day 23 was a Capstone Project where I built a Turtle Crossing game using Python's Turtle graphics module.

The player controls a turtle and attempts to cross the road while avoiding moving cars. The game becomes more challenging as the player progresses.

## Topics Covered

* Object-Oriented Programming (OOP)
* Classes and objects
* Inheritance
* Python Turtle graphics
* Randomization
* Lists
* Loops
* Conditional statements
* Keyboard controls
* Collision detection
* Screen coordinates
* Managing multiple Turtle objects
* Game loops
* Creating and organizing a multi-file project

## What I Learned

During this project, I learned how to structure a larger Python project using multiple classes and files.

I learned how to:

* Create and control a player using a Turtle object.
* Create multiple cars and store them in a list.
* Move individual cars using a loop.
* Generate random car positions and colors.
* Use coordinates to position objects on the screen.
* Detect collisions between the player and cars.
* Detect when the player successfully reaches the other side.
* Increase the difficulty as the game progresses.
* Use classes to organize different parts of a game.

One important concept I learned was how a list can store multiple Turtle objects and how a `for` loop can be used to access and control each object individually.

## Challenges

One of the main challenges was understanding how to create multiple car objects and move them individually.

I also had to understand:

* How Turtle coordinates work on a 600 × 600 screen.
* How `setheading()` controls the direction of a Turtle.
* How `forward()` moves a Turtle based on its heading.
* How to give different cars different movement speeds.
* How to use a loop to repeatedly move all the cars.

The project helped me understand how the concepts I learned in previous days can be combined to create a complete interactive program.

# Day 30 – Password Manager with JSON

## Overview

On Day 30 of the 100 Days of Code challenge, I improved my Password Manager by adding **JSON data storage, password searching, and error handling**.

The application allows users to generate passwords, save website login information, store the information in a JSON file, and search for previously saved login details.

## Topics Covered

* Tkinter GUI
* Functions
* `try`
* `except`
* `else`
* `finally`
* Error handling
* `FileNotFoundError`
* JSON
* `json.load()`
* `json.dump()`
* Dictionaries
* Nested dictionaries
* Updating dictionaries
* File handling
* Reading and writing files
* Password generation
* `random`
* `random.choice()`
* `random.randint()`
* `random.shuffle()`
* `pyperclip`
* Copying passwords to the clipboard
* `messagebox`
* Searching saved data
* Input validation

## What I Learned

* How to use `try` and `except` to handle errors without crashing the program.
* How `FileNotFoundError` can be handled when a file does not exist.
* How `else` runs when the `try` block succeeds.
* How `finally` can be used for code that should run regardless of whether an error occurs.
* How to store structured information using dictionaries.
* How to save Python dictionaries as JSON using `json.dump()`.
* How to retrieve JSON data using `json.load()`.
* How to update dictionary data.
* How to search through stored login information.
* How different functions can work together inside a larger application.
* How to combine Tkinter, JSON, file handling, and error handling into one project.

## Challenges

The biggest challenge was understanding how `try`, `except`, `else`, and `finally` work together.

I also had to understand how JSON files can be used to store and retrieve information and how nested dictionaries are used to organize website, email, and password data.

## Reflection

Day 30 was an important milestone because I learned how to make my applications more reliable and practical.

I learned that errors don't always have to stop a program. With proper error handling, I can anticipate problems and decide what my program should do when they occur.

I also learned how JSON can be used to permanently store structured data, which makes the Password Manager much more useful than the previous version.

Looking back at Day 1, I can see a major difference in what I am now able to build and understand.

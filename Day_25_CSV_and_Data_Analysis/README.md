Day 25 focused on working with CSV files and analyzing data using the Pandas library in Python.

The main project was a **U.S. States Game**, where I used a CSV file containing the names and coordinates of the 50 U.S. states and displayed guessed states on a Turtle map.

## What I Learned

I learned that Pandas makes it much easier to work with large amounts of table-based data.

I learned the difference between a **DataFrame** and a **Series**:

* A DataFrame represents a complete table.
* A Series represents a single column.

I also learned how to select a column using:

```python
data["temp"]
```

and how to find values such as the maximum value using:

```python
data["temp"].max()
```

I learned how CSV data can be used together with Turtle graphics to place information at specific coordinates.

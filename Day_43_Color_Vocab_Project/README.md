# Day 43 – Color Vocabulary Project

## Overview

This project is a simple Color Vocabulary website created using HTML and CSS.

The webpage helps display Spanish color names alongside images representing their corresponding colors. Each color name is styled using CSS so that the text matches the color it represents.

## Topics Covered

* HTML structure
* CSS basics
* Adding CSS to an HTML project
* CSS selectors
* Element selectors
* Class selectors
* The `color` property
* The `font-weight` property
* The `img` element
* The `src` attribute
* Using classes to target specific HTML elements

## What I Learned

In this project, I learned how CSS can be used to change the appearance of HTML elements.

I practiced:

* Linking an external CSS file to an HTML document
* Selecting HTML elements with CSS
* Using classes to style specific elements
* Changing text colors with the `color` property
* Making text bold with the `font-weight` property
* Adding and displaying images
* Organizing HTML and CSS files in the same project

## Project Features

The website includes:

* A main heading
* A Spanish color vocabulary heading
* Spanish color names
* Color images for each vocabulary word
* CSS styling that changes each color name to match its actual color

Examples include:

* Rojo
* Azul
* Other Spanish color vocabulary words

## Challenges

One challenge was understanding how CSS selectors connect to specific HTML elements.

I also practiced using class names so that different elements could receive different styles without changing every element of the same type.

## Reflection

This project helped me understand the relationship between HTML and CSS.

HTML provides the structure and content of the webpage, while CSS controls how the content looks.

I also learned that classes are useful when I want to apply different styles to specific elements.

# Day 44 – Motivational Poster Website

## Overview

Day 44 focused on building a simple motivational poster website using HTML and CSS.

The project displays an image, a motivational message, and a short paragraph. I used HTML to create the structure of the webpage and CSS to control the appearance, positioning, typography, colors, and image styling.

## Topics Covered

* HTML document structure
* HTML elements and attributes
* Images with `<img>`
* `id` attributes
* Paragraphs and headings
* Linking an external CSS file
* CSS selectors
* CSS IDs
* CSS element selectors
* `text-transform`
* `background-color`
* `color`
* `border`
* `width`
* `margin`
* `font-family`
* `text-align`
* Basic webpage positioning

## What I Learned

I learned how to combine HTML and CSS to create a simple styled webpage.

I practiced using an external stylesheet with:

`<link rel="stylesheet" href="./style.css">`

I also learned how CSS can be used to change the appearance of individual elements using IDs, such as applying uppercase text with `text-transform: uppercase`.

I practiced controlling the size and position of elements using properties such as `width`, `margin-left`, and `margin-top`.

I also learned how to style an image with a border and make it responsive within its container using `width: 100%`.

## Challenges

One challenge was understanding how CSS properties affect the positioning and appearance of elements on the webpage.

I also had to understand how IDs and element selectors work differently when styling specific parts of the page.

Getting the image, heading, paragraph, and container positioned correctly required careful use of CSS properties such as width, margins, and text alignment.

## Reflection

Day 44 helped me understand how HTML and CSS work together to create a visually organized webpage.

HTML provides the structure of the page, while CSS controls the design and presentation.

This project also helped me become more comfortable using CSS to control spacing, typography, colors, borders, and positioning instead of relying only on the default browser styling.

# Day 20 – Snake Game (Part 1)

## Overview

Day 20 introduced the first part of building the classic *Snake Game* using Python's Turtle Graphics module. Instead of writing everything in a single file, this project focused on applying *Object-Oriented Programming (OOP)* by creating separate classes to organize the game's logic.

I learned how to build a snake using multiple Turtle objects, move it across the screen, and control its direction with keyboard inputs.

## Project

### Snake Game (Part 1)

This project recreates the beginning of the classic Snake Game. The snake is made from multiple Turtle objects that move together as one. The player controls the snake using the arrow keys while the screen updates continuously to create smooth movement.

---

## Challenges

- Learning how to move each segment in the correct order.
- Understanding the purpose of screen.tracer(0) and screen.update().
- Managing keyboard controls inside a class.

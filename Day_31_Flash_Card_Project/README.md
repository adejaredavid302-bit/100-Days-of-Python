# Day 31 – Flash Card Project

## Overview

On Day 31 of the 100 Days of Code challenge, I built a **French-English Flash Card application** using Python.

The application displays a French word on a flash card and automatically flips the card after 3 seconds to reveal the English translation.

The user can select whether they knew the word or not. Words that are known are removed from the learning list and the remaining words are saved to a CSV file for future practice.

# Day 46 – Billboard Hot 100 YouTube Music Playlist

## Overview

On Day 46 of the 100 Days of Code: Python course, I built a program that takes a date, scrapes the Billboard Hot 100 songs for that date, searches for the songs on YouTube Music, and creates a private playlist containing the songs.

## Topics Covered

- Web scraping with BeautifulSoup
- HTTP requests with Requests
- Working with `ytmusicapi`
- YouTube Music authentication
- Reading and understanding API documentation
- Lists and dictionaries
- Loops
- Exception handling with `try` and `except`
- Working with external Python modules
- File and project organization
- Git and GitHub

## What I Learned

- How to scrape information from a webpage using BeautifulSoup.
- How to extract song titles from HTML elements.
- How to work with `ytmusicapi`.
- How to authenticate with YouTube Music using browser authentication.
- How to create and search YouTube Music playlists.
- How to use dictionary keys such as `title`, `playlistId`, and `videoId`.
- How to use `try` and `except` to allow a program to continue when an individual song cannot be found.
- How to read documentation by identifying the method, parameters, return value, and examples.

## Challenges

One of the main challenges was understanding how the YouTube Music authentication process works.

I also had to learn how the data returned by `ytmusicapi` is structured so that I could correctly access values such as the playlist title, playlist ID, and video ID.

Another important challenge was understanding how to keep authentication information out of my GitHub repository.

## Reflection

Day 46 helped me move beyond simply following instructions and start understanding how to work with documentation and external libraries.

Instead of only copying methods from the course, I practiced examining what functions return and using Python tools such as `type()`, `.keys()`, and `print()` to understand unfamiliar data.
